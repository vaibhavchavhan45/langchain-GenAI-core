# Python Programming Guide

## Introduction

Python is a high-level, interpreted programming language known for its simplicity and readability.

## Basic Syntax

### Variables
Variables in Python don't need explicit declaration:
```python
name = "Rahul"
age = 25
```

### Data Types
Python supports multiple data types:
- **Integers**: `x = 10`
- **Floats**: `price = 99.99`
- **Strings**: `message = "Hello"`
- **Boolean**: `is_valid = True`

## Control Flow

### If-Else Statement
```python
if age >= 18:
    print("Adult")
else:
    print("Minor")
```

### Loops
For loop example:
```python
for i in range(5):
    print(i)
```

## Conclusion

Python is beginner-friendly and widely used in web development, data science, and automation.
